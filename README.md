# CloudLearningTracker



\# Cloud Learning Tracker



A full-stack web application to organize and track cloud learning progress. The application helps users manage topics, subtopics, tasks, notes, and monitor overall learning progress through an interactive dashboard.



\## Features



\- User Registration \& Login

\- JWT Authentication

\- Topic Management

\- Subtopic Management

\- Task Management

\- Notes Management

\- Progress Dashboard

\- Kanban Board

\- Search \& Filtering

\- Responsive UI



\## Technology Stack



\### Frontend

\- Angular

\- TypeScript

\- HTML/CSS



\### Backend

\- .NET 8 Web API

\- Entity Framework Core

\- SQL Server

\- JWT Authentication

\## Getting Started



\### Backend



```bash

cd CloudLearningTracker.API

dotnet restore

dotnet run

```



\### Frontend



```bash

cd CloudLearningTracker.UI

npm install

ng serve

```



Frontend:



```

http://localhost:4200

```



Backend:



```

https://localhost:5168

```
